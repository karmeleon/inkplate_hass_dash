# inkplate_hass_dash
display info from your homeassistant dashboard on your inkplate 6

may also work on other models, i don't own one so i can't tell you. you can try changing the board definition in `platformio.ini`. prs welcome.

[install platformio](https://docs.platformio.org/en/latest/integration/ide/vscode.html#quick-start) and open this repo in it. should install and upload easily afterwards.

best paired with [hass-lovelace-kindle-screensaver](https://github.com/sibbl/hass-lovelace-kindle-screensaver)
